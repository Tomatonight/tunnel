01

本机虚拟网络

每个网络填写一个本机虚拟 IP 和前缀；同一网段只需添加一次。

示例：10.1.0.1/24。多个虚拟网络的地址段不能重叠；所有地址共用一张虚拟网卡。

自动获取虚拟 IP 可选，需已有分配服务

按分配服务申请网段中的本机 IP；申请的网段不能与手动配置的网络重叠。

02

连接节点

填写对端 IP，未填写端口时使用 65535；通信双方必须使用同一个共享密钥。

尚未添加节点。添加后即可建立认证连接。

发布内网 可选，让其他节点访问本机后方网络

先选择所属虚拟网络，再填写要开放的内网网段。多个节点发布同一网段时，系统会自动选择可用入口。

Android 只能访问其他节点发布的内网，不能发布本机内网。已导入的发布项需要移除后才能保存或连接。

发布网段不能覆盖本机虚拟网络，也不能与其他发布网段重叠；保存时由核心校验。

提供 IP 分配服务 可选，管理地址池和接入密钥

本次保存仅包含分配服务；切回普通模式可恢复当前窗口中暂存的隧道参数。

持有这把密钥的节点可申请全部地址池。需要单独撤销节点或防止持钥者冒用其他节点地址时，可使用高级设置中的逐节点授权。

可分配地址池

填写地址段，例如 10.1.0.0/24；地址池只用于分配，不会让本机自动加入该网络。

当前使用逐节点授权；每个节点只可申请勾选的地址池。

授权接入节点

将导出的接入配置交给客户端导入。分配服务不会自动建立节点间的 peer 连接。

服务高级设置 授权方式、绑定与回收
高级设置 设备、监听、MTU 与 JSON

关闭后仍会主动连接已配置节点；已建立邻接可使用所选数据封装。

每个节点仍受下方网络授权限制。取消后可单独选择允许入站的网络。

01

只填必要信息

开启监听时填写本机绑定地址；至少配置一个虚拟网络，可手动填写本机 IP/前缀，也可通过分配服务获取。需要连接节点时，再填写对端地址与密钥。

02

网络授权独立

新增虚拟网络不会自动授权已有节点。配置多个网络时，请为每个节点选择允许加入的网络。

03

保存并应用

连接时会校验并保存当前配置。运行中也可以保存并应用修改，无需手动断开。
